Ekdal
Välkommen till Ekdal. Klicka på marken för att gå och på träd, stenar och fiskeplatser för att samla. Prata med folk som har ett gult utropstecken ovanför sig för att få uppdrag. Dra för att vrida kameran och scrolla för att zooma.
Hälsa 10/10

28 platser. Klicka på mat för att äta och på vapen för att ta på dem. Andra föremål slängs när du klickar.
